# مدیریت کتابخانه

یک سیستم مدیریت کتابخانه ساده پیاده‌سازی کنید که قابلیت‌های زیر را داشته باشد:

## قابلیت‌ها

- **افزودن کتاب‌ جدید**:  
  کاربران اجازه افزودن کتاب به فهرست کتابخانه را داشته باشند.

- **مشاهده لیست کتاب‌ها**:  
  کاربران امکان مشاهده لیست کتاب‌ها را داشته باشند.

- **جستجو**:  
  کاربران باید بتوانند اطلاعات مربوط به یک کتاب خاص یا لیست کتاب‌های یک نویسنده را با وارد کردن نام کتاب یا نام نویسنده مشاهده کنند.

- **ویرایش کتاب**:  
  کاربران باید بتوانند کتاب‌های موجود را ویرایش کنند.

- **حذف کتاب**:  
  کاربران باید بتوانند کتاب‌های موجود را حذف کنند.

- **فیلتر کردن کتاب‌ها**:  
  امکان فیلتر کردن کتاب‌ها توسط کاربران بر اساس قیمت یا تاریخ انتشار فراهم شده باشد.

- **حذف با فیلتر**:  
  کاربران باید بتوانند کتاب‌‌هایی که فیلتر کرده‌اند را حذف کنند.

## نکته‌ها

- قبل از شروع پیاده‌سازی، **حتماً نمودار ER** مورد نیاز را طراحی کنید.
- برای پیاده‌سازی این سؤال باید از **مفاهیم Django و Django Template** استفاده کنید.
- از **قالب مناسب برای پروژه** استفاده کنید و اطلاعات مورد نیاز را با فرمت مناسب نمایش دهید.
- استفاده از **Git در این پروژه ضروری** می‌باشد.  
  برای ارسال پاسخ این سؤال کافی است که لینک ریپو GitHub خود را در یک **فایل متنی (txt)** قرار داده و ارسال کنید.
