# نرمال‌سازی پایگاه داده سوپرمارکت

در این پروژه، هدف **نرمال‌سازی دیتابیس اولیه‌ی سوپرمارکت** است که طراحی آن دارای **افزونگی بالا** و **وابستگی‌های نامناسب** است.

---

## 🗃️ ساختار جدول اولیه

| نام ستون | نوع داده | تعریف |
|----------|----------|--------|
| m_id | BIGINT AUTO_INCREMENT | آی‌دی شعبه *(کلید)* |
| m_name | VARCHAR(255) | نام شعبه |
| m_address | TEXT | آدرس شعبه |
| p_id | BIGINT AUTO_INCREMENT | آی‌دی محصول *(کلید)* |
| p_name | VARCHAR(255) | نام محصول |
| p_weight | BIGINT | وزن محصول |
| price | BIGINT | قیمت محصول |
| level | INT | سطح شعبه |
| m_score | BIGINT | امتیاز شعبه |
| capacity | BIGINT | ظرفیت تعداد محصول مربوط به سطح شعبه |

> 🔸 کلیدها: `m_id` و `p_id`  
> 🔸 طراحی بالا دچار افزونگی و نقض وابستگی‌هاست.

---

## 🎯 مطلوبات

### وظیفه شما:

- **نرمال‌سازی کامل جدول اولیه با دستورات DDL**
- ساخت جداول جدید طبق سطح نرمال‌سازی مناسب
- استفاده از **نام جداول مجاز و استاندارد زیر:**

| نوع داده | نام جدول |
|----------|-----------|
| شعبه‌ها | `markets` |
| امتیازات | `scores` |
| محصولات | `products` |
| نام‌ها | `names` |
| وزن‌ها | `weights` |
| آدرس‌ها | `addresses` |
| قیمت‌ها | `prices` |
| ظرفیت‌ها | `capacities` |

---

## ⚠️ نکات مهم

- **تمام ستون‌ها NOT NULL** باشند.
- تنها از **جداول موردنیاز** استفاده شود (نه همه‌ی جدول‌های پیشنهادی).
- کلیدهای خارجی (`FOREIGN KEY`) باید **به‌درستی تعریف** شوند.
- از تغییر در نام ستون‌ها **اکیداً خودداری کنید** (دقیقاً مطابق جدول اولیه باشند).
- فقط از **دستورات DDL (CREATE TABLE)** استفاده شود.

---

## 📤 آن‌چه باید ارسال کنید

یک فایل با پسوند `.sql` که فقط شامل **دستورات `CREATE TABLE`** باشد و نرمال‌سازی را کامل انجام داده باشد.

> 💡 اگر می‌خواهی فایل `.sql` برای این ساختار نرمال شده را هم تولید کنم، کافیه بگی تا آماده‌اش کنم.
