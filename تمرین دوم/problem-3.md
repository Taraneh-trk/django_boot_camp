# زوج زوج

مریم قصد دارد دو جوان موجه را عاقبت‌به‌خیر کند. او به این نتیجه رسیده که هرچه زیردنباله مشترک بین نام دو جوان طولانی‌تر باشد، زندگی مشترک پایدارتری خواهند داشت.

از آنجا که وقت کافی برای بررسی دستی طول زیردنباله‌ها ندارد، از شما کمک می‌خواهد تا برای هر فرد، مناسب‌ترین گزینه برای زندگی مشترک را بر اساس طولانی‌ترین زیردنباله مشترک انتخاب کنید.

---

## ورودی

* خط اول: نام فرد مورد نظر مریم
* خط دوم: عدد `n` که تعداد گزینه‌های دم‌بخت موجود است
* در `n` خط بعدی: اسامی گزینه‌ها (تمام حروف lowercase و طول هر رشته ≤ 100)

محدوده‌ها:
$1 \leq \text{length(name)}, n \leq 100$

---

## خروجی

خروجی شامل ۲ خط است:

1. زیردنباله مشترک بین نام فرد مورد نظر و نام گزینه برگزیده
2. طول این زیردنباله

---

## مثال

### ورودی نمونه ۱

```
farideh
3
gholam
arshia
ahmad
```

### خروجی نمونه ۱

```
arh
3
```

---

## توضیح مثال

* طولانی‌ترین زیردنباله مشترک بین `farideh` و `gholam` برابر با ۱ است (مثلاً "a" یا "h").
* طولانی‌ترین زیردنباله مشترک بین `farideh` و `arshia` برابر با ۳ است ("arh").
* طولانی‌ترین زیردنباله مشترک بین `farideh` و `ahmad` برابر با ۲ است ("ah").

بنابراین گزینه برگزیده `arshia` است که طولانی‌ترین زیردنباله مشترک را دارد.
