# 🐳 داکرایز کردن پروژه "مدیریت کتابخانه"

در این تمرین، از شما خواسته شده است که **مینی‌پروژه اول فردی (مدیریت کتابخانه)** خود را با استفاده از **Docker** داکرایز کرده و آماده اجرا نمایید.

---

## 🧱 مراحل مورد انتظار

### 1. داکرایز کردن پروژه

شما باید با استفاده از ابزارهای زیر پروژه را کانتینری کنید:

- `Dockerfile` برای تنظیم اجرای Django
- `docker-compose.yml` برای بالا آوردن سرویس‌ها شامل:
  - سرویس اصلی Django
  - پایگاه داده (مثلاً PostgreSQL یا MySQL)
  - (اختیاری) سرویس‌های دیگر مانند pgAdmin

### 2. اجرای موفق پروژه با Docker

اطمینان حاصل کنید که پس از اجرای:
