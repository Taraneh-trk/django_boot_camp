# اشتراک ویدیو

این مینی‌پروژه با هدف پیاده‌سازی یک **وب اپلیکیشن اشتراک ویدیو** طراحی شده است.

اپلیکیشن به کاربران این امکان را می‌دهد که با پرداخت هزینه‌ای، به محتوای ویدیویی دسترسی داشته باشند.

---

## اهداف پروژه

### مدل‌سازی داده‌ها

مدل‌های پیشنهادی:

- **کاربر**
- **ویدیو**
- **اشتراک**
- **تاریخچه**

### ایجاد API

- **احراز هویت کاربر**
- **مدیریت ویدیو**
- **مدیریت اشتراک**
- **مشاهده تاریخچه تماشا و پرداخت**

### مدیریت پرداخت

- استفاده از **API درگاه بانکی** (اختیاری)
- پیاده‌سازی منطق **تمدید و لغو اشتراک**

### مدیریت مجوزها

- کنترل **دسترسی به محتوا بر اساس نوع اشتراک کاربر**

### بروزرسانی زنده وضعیت ویدیوها

- ارائه **بروزرسانی‌های زنده** درباره وضعیت ویدیوها شامل:
  - تعداد تماشا
  - امتیازها
  - نظرات جدید

---

## نکات

- قبل از شروع پیاده‌سازی، **حتماً نمودار ER** مورد نیاز را طراحی کنید.
- در صورت تمایل می‌توانید **موارد اضافه‌تری** به پروژه اضافه کنید.  
  مدل‌های ذکرشده صرفاً **پیشنهادی** هستند.
- برای پیاده‌سازی این پروژه باید از مفاهیم **جنگو** و **جنگو رست** استفاده کنید.
- **نیازی به داشتن رابط کاربری نیست** و صرفاً نوشتن API کفایت می‌کند (API باید به درستی کار کند).
- استفاده از **Git در این پروژه ضروری** می‌باشد.  
  برای ارسال پاسخ این سؤال، کافی است لینک ریپو GitHub خود را در یک **فایل متنی (.txt)** قرار داده و ارسال کنید.
- مباحث این مینی‌پروژه تقریباً **سه هفته** از مباحث بوت‌کمپ را پوشش می‌دهد.  
  در نتیجه ممکن است مواردی در این پروژه باشد که **تا قبل از اتمام زمان آن آموزش داده شود**.
