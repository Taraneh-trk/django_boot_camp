##  پاسخ نهایی (دستور یک‌خطی awk):

```bash
awk -F'|' 'BEGIN { print "col1 - col2 - col3" } { print $1 " - " $2 " - " $3; sum += $3 } END { print sum }' data.txt
```

---

##  توضیح بخش به بخش دستور:

* `-F'|'` → تعیین جداکننده فیلدها (delimiter) به صورت `|`.
* `BEGIN { print "col1 - col2 - col3" }` → قبل از شروع پردازش، هدر جدول را چاپ می‌کند.
* `{ print $1 " - " $2 " - " $3; sum += $3 }` → برای هر خط، مقادیر را با فرمت مورد نظر چاپ کرده و ستون سوم را به متغیر `sum` اضافه می‌کند.
* `END { print sum }` → پس از پایان پردازش فایل، مجموع مقادیر ستون سوم را چاپ می‌کند.
