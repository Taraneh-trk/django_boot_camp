# دفترچه تلفن – پروژه پایتون 📱

در شهری کوچک به نام **کدستان**، مهندسی خلاق به نام **آرمان** تصمیم گرفت برای حل مشکل یافتن و مدیریت شماره تماس دوستان و همکارانش، یک **دفترچه تلفن دیجیتال** طراحی کند.
اکنون او از شما کمک می‌خواهد تا این برنامه را با زبان **Python** پیاده‌سازی کنید.

---

## 🎯 اهداف برنامه

برنامه دفترچه تلفن باید قابلیت‌های زیر را داشته باشد:

1. **➕ اضافه کردن مخاطب جدید**

   * کاربر بتواند نام، شماره تلفن و ایمیل مخاطب جدیدی را ذخیره کند.

2. **✏️ ویرایش مخاطب**

   * کاربر بتواند اطلاعات یک مخاطب ذخیره‌شده را به‌روزرسانی کند.

3. **❌ حذف مخاطب**

   * کاربر بتواند مخاطبی را بر اساس **نام** حذف کند.

4. **📋 نمایش تمام مخاطبین**

   * لیستی از تمام مخاطبین ذخیره‌شده نمایش داده شود.

5. **🔤 مرتب‌سازی مخاطبین**

   * مخاطبین بر اساس **نام** مرتب و نمایش داده شوند.

6. **💾 ذخیره‌سازی و بازیابی اطلاعات**

   * اطلاعات مخاطبین باید در یک فایل ذخیره شوند تا بعد از بسته شدن برنامه از بین نروند.
   * اطلاعات باید در اجرای بعدی برنامه به درستی بازیابی شوند.

---

## 🛠 راهنمای پیاده‌سازی

* از **فرمت JSON یا CSV** برای ذخیره‌سازی اطلاعات استفاده کنید.
* از **کتابخانه‌های استاندارد پایتون** برای مدیریت فایل‌ها بهره ببرید.
* برای جستجو و حذف مخاطبین از **لیست‌ها** و **حلقه‌ها** استفاده کنید.
* برای **صحت‌سنجی ورودی‌ها** (مانند شماره و ایمیل) از **Regex** استفاده شود.
* استفاده از **Git** الزامی است؛ برای ارسال پروژه:

  * پروژه را در یک **مخزن گیت‌هاب** قرار دهید.
  * لینک ریپو را در یک فایل متنی (مثلاً `github_link.txt`) ذخیره کرده و ارسال کنید.

---

## 🧪 پیشنهادات برای تست

* اضافه کردن چند مخاطب با اطلاعات مختلف
* ویرایش یکی از مخاطبین
* حذف مخاطبی که در لیست وجود دارد
* تلاش برای حذف مخاطبی که وجود ندارد
* بستن و باز کردن دوباره برنامه برای بررسی ماندگاری داده‌ها
* مرتب‌سازی لیست مخاطبین
